01

Source documents, bound to the calculation

The exercise record from your Carta export, the merchant-banker FMV certificate, and the official RBI reference rate for the exact exercise date. Each is snapshotted at ingest and locked to the calculation permanently. No market-rate fallbacks, no silent substitutions.

02

Deterministic to the paisa

Spread becomes perquisite under Section 17(2)(vi), then itemised TDS with surcharge, cess, interest and penalty. The arithmetic is pure decimal, run against date-versioned rule packs that cite the statute. The same inputs return the same rupee every time.

The review screen sets evidence against output: certificate page, FX snapshot and citations on the left, the full breakup and rendered forms on the right. One explicit Approve & Export action releases the package, and nothing leaves without it.

The liability firewall

Every number is checked twice, by strangers.

Before a package can be approved, an independent verifier recomputes every value printed on every form. It deliberately shares no code with the calculation engine. A single mismatch locks the package and disables approval until it is resolved.

  • Every monetary value re-derived from the source evidence, not the form.
  • FX date must equal the exercise date. Exact match, no nearest-day.
  • FMV certificate window checked against Rule 3(8)'s 180-day limit.
  • Breakups must sum: base, surcharge, cess, interest, penalty, to the paisa.
